# MQF Portfolio Risk

This project explores Monte Carlo simulation, portfolio risk, and VaR backtesting for a multi-asset stock portfolio.

## Recommended file order

1. `data.py` - download and prepare the stock data
2. `simulation.py` - build the Monte Carlo return simulations
3. `risk.py` - calculate VaR and CVaR
4. `optimization.py` - optional optimization helpers for portfolio weights
5. `backtesting.py` - test VaR forecasts against actual returns
6. `main.py` - run the workflow end-to-end
7. `results/` - store generated tables and plots

## Structure

- `data.py` - data retrieval and historical return preparation
- `simulation.py` - Monte Carlo simulation models
- `risk.py` - VaR and CVaR calculations
- `optimization.py` - portfolio optimization helpers
- `backtesting.py` - VaR backtesting logic
- `main.py` - orchestration script
- `results/` - plots and tables generated by the workflow

## Run

```bash
python MQF_Portfolio_Risk/main.py
```
